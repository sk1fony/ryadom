# Ryadom

[English](README.md)

Передача файлов и текста между компьютером и телефоном по локальной сети, без регистрации и приложения на телефоне

## Запуск

Установи [Python 3.10+](https://www.python.org/downloads/), скачай проект и распакуй архив

| Система | Запуск |
| --- | --- |
| Windows | Открой `start.bat` |
| macOS | Выполни `sh start.command` |
| Linux | Выполни `sh start.sh` |

Команды выполняй из папки проекта. При первом запуске нужен интернет для установки библиотеки QR-кодов. Дальше Ryadom работает без интернета. Оставь терминал открытым на время работы

## Подключение

1. Подключи телефон и компьютер к одной локальной сети
2. Отсканируй QR-код на компьютере
3. Введи шестизначный код на телефоне

Код обновляется каждые 15 секунд. Для обмена файлами и текстом используй **Отправить / Получить**. Язык интерфейса меняется через **En / Ru**

Если телефон не подключается, проверь доступ к локальной сети в VPN и разрешение Python для частных сетей в брандмауэре

## Файлы и текст

Полученные на компьютер файлы сохраняются в `~/Downloads/Ryadom`. Лимит по умолчанию: **6 ГиБ на файл**

Для отправки с компьютера создаются временные копии. Полученные файлы остаются после закрытия Ryadom, а текст очищается при завершении программы или обновлении QR

Обновление QR отключает подключённые устройства. Передача идёт по локальному HTTP без шифрования, поэтому используй доверенную сеть

## Параметры

```sh
python3 bootstrap.py --port 9000 --storage ./received --max-file-mb 6144
```

На Windows используй `python`. Все параметры доступны через `--help`
