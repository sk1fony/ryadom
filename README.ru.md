# Ryadom

[English](README.md)

Передача файлов и текста между устройствами по локальной сети

[Download](https://github.com/sk1fony/ryadom/releases/tag/ryadom)

## Запуск

Установи [Python 3.10+](https://www.python.org/downloads/), скачай проект и распакуй архив

| Система | Запуск |
| --- | --- |
| Windows | Открой `start.bat` |
| macOS | Выполни `sh start.command` |
| Linux | Выполни `sh start.sh` |

Команды выполняй из папки проекта !Оставь терминал открытым на время работы!

## Подключение

1. Подключи телефон и компьютер к одной локальной сети
2. Отсканируй QR-код 
3. Введи код на телефоне

Если телефон не подключается, проверь доступ к локальной сети в VPN и разрешение Python для частных сетей в брандмауэре

## Файлы и текст

Полученные на ПК файлы сохраняются в `~/Downloads/Ryadom` Лимит по умолчанию: **6 ГиБ на файл**

Обновление QR отключает подключённые устройства. Передача идёт по локальному HTTP без шифрования, поэтому используй доверенную сеть

## Параметры

```sh
python3 bootstrap.py --port 9000 --storage ./received --max-file-mb 6144
```

На Windows используй `python`. Все параметры доступны через `--help`
